# core mod

The base game as a mod: rulesets, converted scripts, and game data. See docs/strategy.md, section 6.

The server builds core's files when it starts: rAthena's item scripts, converted to `data/items.yml` and `scripts/items/*.lua` (mods/README.md, "Core's item scripts", and [decision 0007](../../docs/decisions/0007-converted-item-scripts.md)). This folder holds no files of its own yet.
