# NPC script coverage: pre-renewal

Generated by `wactl convert npcs --report`; do not edit. `go test ./tools/convert` checks that it is current.

A script NPC is placed when its own script converts whole. It converts fully when the functions it calls convert whole too, and partly when a function has parts that fail when a script reaches them. Shops and barter shops become data in core's `data/npcs.yml`. A shop converts partly when some of its items do not convert.

- Shops that are not placed have no map or no sprite: scripts open them with `callshop`, which converts to `player:open_shop`.
- cashshop, itemshop, pointshop, marketshop and barter shops become shops with a cost and a stock. Players cannot sell to them, as in rAthena.
- A cashshop's price is in cash points only. rAthena also lets Kafra points pay part of it, which does not convert.
- A pointshop's variable becomes a currency: #CASHPOINTS is `cash`, #KAFRAPOINTS is `kafra`, and other variables are new records of core's `data/currencies.yml`. Reads and changes of these variables use the currency calls.
- A barter item that is refined, that takes refined items or more than 5 kinds of items, or that the barter sells a second time, does not convert.
- 0 currencies were added for pointshop variables.
- Pushcart rental converts: F_KafCart gives the cart with `player:set_cart`.
- rAthena's getitem and delitem do nothing for an amount of 0 or less, and wAthena's calls raise an error. 0 scripts and functions have a fixed amount of 0 or less, which converts to nothing. 53 have a computed amount, which `R.give_item` and `R.take_item` check first.

## Touch areas

`OnTouch` and `OnTouch_` labels become the `touch` event, and the line's span the record's `touch` field (review decision 55). `OnTouch_` runs for one player at a time through `R.touch_one`. A touch handler runs in a conversation with the player, so a label with a dialog converts (review decision 56). A touch label that does not convert fails on other commands, which the command table lists.
